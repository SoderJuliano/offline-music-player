# Offline Music Player

## Descrição
Aplicativo web para ouvir músicas offline com suporte a playlists, pesquisa, reprodução em background, e conexão peer-to-peer para troca de músicas.

## Configuração
Requisitos:
- Node.js ^20.19.0 ou >=22.12.0
- Dependências listadas no package.json

Instalação:
1. Clone o repositório
2. Execute `npm install`

## Dependências principais e versões atualizadas

- Vue: ^3.5.18
- Vue Router: ^4.6.4
- vue-i18n: ^11.1.12
- dexie: ^3.2.7
- simple-peer: ^9.11.1
- ably: ^2.17.0

## Comandos úteis
- `npm run dev`: iniciar o servidor de desenvolvimento
- `npm run build`: construir o projeto
- `npm run format`: formatar o código com prettier

## Notas
- O projeto utiliza Vite para build e plugins como pwa, mkcert, vue-devtools.
- As versões das dependências são compatíveis com o package.json atual.
